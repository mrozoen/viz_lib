Compute

7 services

Amazon EC2

59× answer · 95× decoy

Virtual servers. The service that gives you the highest level of control over the underlying infrastructure — and, because of that, the most customer responsibility: you patch the OS, configure the firewall, and manage everything above the hypervisor.

Signals"full control over the operating system" · "install custom / self-managed software" · "run a self-managed database" · "licensing requires a specific OS" · almost every shared responsibility question is built on EC2
TrapEC2 does not run at edge locations — it runs in Availability Zones. It is also not the answer when the stem says "without managing servers" or "focus on the application, not the infrastructure."

AWS Elastic Beanstalk

8× answer · 7× decoy

You upload code; AWS handles capacity provisioning, load balancing, Auto Scaling and health monitoring for you. You keep full control of the underlying resources and pay only for them — Beanstalk itself is free.

Signals"quickly deploy" + "has no cloud experience" · "deploy an existing .NET / Node.js / Java application" · "manage the deployment details for me"
TrapNot for event-driven code — that is Lambda. Not infrastructure as code — that is CloudFormation.

AWS Batch

2× answer · 11× decoy

Runs batch computing jobs at any scale, provisioning the compute for you.

Signals"large numbers of batch jobs" · "queue of processing work"

Amazon Lightsail

2× answer · 13× decoy

The simplest way to launch a small application — a virtual server, storage and networking bundled at a predictable monthly price.

Signals"simplest" · "small business, minimal configuration" · "predictable monthly price" · "pre-configured WordPress / LAMP stack"

AWS Outposts

0× answer · 4× decoy

Physical AWS-managed racks installed in your own data center, running AWS services on-premises with the same APIs.

Signals"must remain on-premises for latency or data residency, but I want AWS services"

AWS Local Zones

not seen in corpus

AWS infrastructure placed close to a large population centre, for single-digit millisecond latency to end users in that metro area.

AWS Wavelength

not seen in corpus

AWS compute embedded inside 5G carrier networks, for mobile applications needing ultra-low latency.

Serverless and Containers

5 services

AWS Lambda

21× answer · 16× decoy

Runs your code in response to events, with no servers to provision or manage. You are billed per request and per millisecond of execution — when the code is not running, you pay nothing. Maximum execution time is 15 minutes.

Signals"event-driven" · "triggered by" · "run code without provisioning or managing servers" · "reduce the compute footprint" · any question containing the word serverless
TrapA long-running or always-on application is not Lambda. "Serverless" in a database question means DynamoDB, not Lambda.

AWS Fargate

1× answer · 9× decoy

The serverless compute engine for containers. ECS and EKS run your containers; Fargate is the option that removes the EC2 instances underneath them.

Signals"containers" and "without managing servers or clusters"

Amazon ECS

3× answer · 11× decoy

AWS's own container orchestration service — it installs, operates and scales the cluster management infrastructure for you.

Signals"container service" + "manage the cluster" · Docker workloads without Kubernetes

Amazon EKS

not seen in corpus

Managed Kubernetes. If the stem says Kubernetes, this is the answer.

Amazon ECR

0× answer · 2× decoy

A registry for container images — it stores images, it does not run them.

TrapAppears as a decoy in "which container service runs / scales your containers" questions. Registry = storage.

Storage

8 services

Amazon S3

36× answer · 59× decoy

Object storage: virtually unlimited, 99.999999999% durable, automatically replicated across multiple Availability Zones. Serves static websites, offers versioning and lifecycle rules, and is regional, not global.

Signals"objects" · "photos, videos, documents" · "static website" · "downloadable over the internet" · "unlimited storage that scales automatically"
TrapS3 is regional — it is a classic wrong pick on "which services are global". Protection from accidental deletion is versioning (plus MFA Delete); blocking public objects is S3 Block Public Access.

Amazon S3 Glacier

6× answer · 24× decoy

Archival storage classes: the lowest cost per gigabyte, in exchange for retrieval that takes minutes to hours. Glacier Deep Archive is cheapest of all, with 12-hour retrieval.

Signals"archive" · "retain for 5 / 7 / 10 years" · "regulatory retention" · "lowest cost" + "rarely accessed"
TrapIf the stem says the data must be available immediately, it is not Glacier — that is S3 Standard-IA or One Zone-IA.

Amazon EBS

10× answer · 52× decoy

Block storage attached to a single EC2 instance — a virtual hard drive. It persists independently of the instance, lives in one Availability Zone, and is backed up with snapshots to S3.

Signals"persistent storage for an EC2 instance" · "a database running on EC2" · "high read/write on one instance" · "snapshots"
TrapEBS is one-instance-at-a-time. If several instances must share the same files, it is EFS. Instance store, not EBS, is the ephemeral storage that vanishes when an instance stops.

Amazon EFS

8× answer · 20× decoy

A shared file system (NFS) that many EC2 instances — and on-premises servers — can mount at the same time, growing and shrinking automatically.

Signals"multiple instances access the same files simultaneously" · "NFS" · "shared file storage" · "Linux"

AWS Storage Gateway

8× answer · 12× decoy

Hybrid storage: lets on-premises applications use AWS cloud storage through standard file, volume and tape protocols, without rewriting them.

Signals"on-premises applications" + "seamlessly use cloud storage" · "extend on-premises storage into AWS" · "virtual tape library"
TrapOn "which TWO extend an on-premises architecture into AWS", the pair is usually Direct Connect + Storage Gateway.

Amazon FSx

not seen in corpus

Fully managed third-party file systems — FSx for Windows File Server (SMB, Active Directory) and FSx for Lustre (high-performance computing).

Signals"Windows file shares" · "SMB" · "Lustre" · "HPC scratch storage"

AWS Backup

0× answer · 3× decoy

Centralised, policy-based backup across EBS, RDS, DynamoDB, EFS and more, from one console.

AWS Elastic Disaster Recovery

not seen in corpus

Continuously replicates servers into AWS so you can fail over quickly after an outage, and fail back afterwards.

Database

7 services

Amazon RDS

21× answer · 34× decoy

Managed relational database — MySQL, PostgreSQL, MariaDB, Oracle, SQL Server and Aurora. AWS handles provisioning, OS and database patching, backups and failover; you handle the schema, the queries and the data. Multi-AZ gives you a synchronous standby with automatic failover and an unchanged endpoint; read replicas give you read scaling.

Signals"relational" · "joins" · "complex transactions" · "ACID" · "OLTP" · "managed MySQL/Oracle/SQL Server" · "don't have DBAs for routine tasks"
TrapPatching an RDS instance is AWS's job. If the same database runs on EC2, patching becomes the customer's job — this inversion is one of the most common shared-responsibility questions on the exam.

Amazon DynamoDB

17× answer · 31× decoy

Managed NoSQL key-value database. Serverless, single-digit millisecond latency at any scale, replicated across three Availability Zones automatically.

Signals"NoSQL" · "non-relational" · "key-value" · "document store" · "single-digit millisecond" · "serverless database" · "scales automatically without intervention"

Amazon Aurora

6× answer · 18× decoy

AWS's own relational engine, MySQL- and PostgreSQL-compatible, up to five times the throughput of standard MySQL, with storage that grows automatically.

Signals"MySQL-compatible" + "five times faster" · "storage scales automatically" · "cloud-native relational"

Amazon ElastiCache

5× answer · 16× decoy

Managed in-memory cache (Redis or Memcached) that sits in front of a database to serve frequently-read data in microseconds.

Signals"cache database query results" · "reduce load on the database" · "sub-millisecond" · "most frequently accessed data"
TrapThe word "cache" also appears in CDN questions. Caching content for distant users is CloudFront; caching database reads is ElastiCache.

Amazon Redshift

7× answer · 35× decoy

Managed data warehouse for analytics and business intelligence over very large datasets.

Signals"data warehouse" · "consolidate data from many sources for analysis" · "petabyte-scale analytics" · "OLAP"
TrapThirty-five appearances as a decoy: it is dropped into ordinary database questions to see if "Redshift" reads as generic AWS database. It is analytics only.

Amazon Neptune

1× answer · 7× decoy

Graph database — relationships between highly connected data: social networks, recommendation engines, fraud rings.

Amazon DocumentDB · Amazon MemoryDB for Redis

0× answer

DocumentDB is managed MongoDB-compatible document storage. MemoryDB is a durable in-memory Redis database (unlike ElastiCache, it is a primary database, not just a cache).

Networking and Content Delivery

10 services

Amazon CloudFront

29× answer · 31× decoy

The content delivery network. Caches content at edge locations worldwide so users far from your Region get low latency and high transfer speeds. It is a global service, and it integrates with Shield and WAF, which is why it also turns up in DDoS answers.

Signals"users around the world" + "latency" · "CDN" · "cache static content closer to users" · "deliver video globally" · "edge locations"
TrapOn DDoS questions CloudFront is a legitimate answer alongside Shield and WAF — it absorbs and filters traffic at the edge, before it reaches your origin.

AWS Direct Connect

19× answer · 35× decoy

A dedicated physical network connection from your data center to AWS. Consistent performance, and it does not traverse the public internet. Requires an ISP and a colocation facility, and takes weeks to provision.

Signals"dedicated" · "private" · "consistent / predictable network performance" · "does not use the public internet" · "large daily data transfers, business critical"
TrapIf the stem says over the public internet or set up quickly / cheaply, it is VPN, not Direct Connect. This exact swap has cost you marks before.

AWS VPN

10× answer · 14× decoy

An encrypted IPsec tunnel between your network and AWS, running over the public internet. Cheap and fast to set up; performance depends on the internet.

Signals"securely connect over the public internet" · "encrypted tunnel" · "IPsec" · "needed this week" · Site-to-Site or Client VPN by name

Amazon VPC

13× answer · 34× decoy

Your logically isolated virtual network in AWS: subnets, route tables, internet gateways, security groups (instance-level, stateful) and network ACLs (subnet-level, stateless). VPC Flow Logs capture IP traffic information.

Signals"virtual network dedicated to your account" · "subnets" · "network ACLs" · "capture information about IP traffic" (Flow Logs) · "connect two VPCs" (peering)
TrapA VPC sits inside one Region. "Geographically isolated locations" is multiple Regions, never a VPC.

Amazon Route 53

12× answer · 23× decoy

Managed DNS and domain registration, with health checks and routing policies (latency, geolocation, weighted, failover). A global service that runs at edge locations.

Signals"DNS" · "register a domain name" · "route users to the nearest Region" · "health checks" · "cross-Region traffic management"
TrapLoad balancing across Regions is Route 53 or Global Accelerator. ELB is regional and cannot do it.

Elastic Load Balancing

9× answer · 27× decoy

Distributes incoming traffic across multiple targets in multiple Availability Zones, which is what makes an architecture highly available. Types: Application (HTTP/HTTPS), Network (TCP/UDP, ultra-low latency) and Gateway.

Signals"distribute traffic across instances" · "no single point of failure" · "highly available web tier" · usually paired with Auto Scaling on Choose TWO

AWS Global Accelerator

5× answer · 3× decoy

Gives you static anycast IP addresses and routes users over the AWS global network to the best-performing healthy endpoint, across Regions.

Signals"static IP addresses" · "route to the healthiest regional endpoint" · "improve performance for a global audience" for non-cacheable or non-HTTP traffic
TrapCloudFront caches content; Global Accelerator routes connections. If the workload is TCP/UDP or dynamic, it is Global Accelerator.

AWS Transit Gateway

4× answer · 6× decoy

A network hub connecting thousands of VPCs and on-premises networks through a single gateway, replacing a mesh of peering connections.

Signals"hundreds / thousands of VPCs" · "simplify connection management" · "scale connectivity"

Amazon API Gateway

0× answer · 6× decoy

Create, publish and secure APIs at any scale; commonly the front door to Lambda.

TrapNever correct in this corpus, but appears six times as a decoy — usually in VPC and network-ACL questions where it has no role.

AWS PrivateLink

0× answer · 2× decoy

Private connectivity between VPCs and AWS services without traversing the internet, using interface VPC endpoints.

Security, Identity, and Compliance

20 services

AWS IAM

33× answer · 57× decoy

Controls who can do what in your account: users, groups, roles and policies. Free, and global rather than regional. Best practices the exam tests constantly: grant least privilege, enable MFA, attach permissions to groups not individuals, use roles for applications and temporary access, and never use the root user for daily work.

Signals"manage user permissions" · "control what each developer can access" · "apply common access controls to many users" (groups) · "at no additional cost"
TrapRoles for temporary access and for applications on EC2 — never access keys stored on the instance. An IAM credential report lists all users and the status of their credentials.

AWS Artifact

19× answer · 12× decoy

A self-service portal for on-demand access to AWS compliance reports and agreements — SOC 1/2/3, PCI DSS, ISO certifications, and BAAs.

Signals"SOC report" · "PCI" · "ISO" · "auditor requests" · "compliance documentation" · "download reports on demand" · "agreements with AWS"
TrapOne of the most reliable one-to-one mappings on the exam: compliance report → Artifact. Nineteen questions, always the same answer.

AWS WAF

9× answer · 15× decoy

A web application firewall that inspects HTTP/HTTPS requests and blocks them by rule — SQL injection, cross-site scripting, specific IP addresses, rate limits.

Signals"SQL injection" · "cross-site scripting" · "block requests from a set of IP addresses" · "filter malicious web requests" · layer 7
TrapWAF blocks; GuardDuty only detects. When a stem says "block the malicious traffic", GuardDuty is the decoy.

AWS Shield

6× answer · 15× decoy

DDoS protection. Shield Standard is free and always on for every customer. Shield Advanced adds bigger-attack mitigation, cost protection against scaling charges, and 24/7 access to the AWS Shield Response Team.

Signals"DDoS" → Shield. "DDoS" plus "assistance from AWS experts" or "cost protection" → Shield Advanced.

AWS KMS

6× answer · 6× decoy

Creates and manages encryption keys, and controls their use across AWS services — EBS, S3, RDS, CloudTrail and the rest.

Signals"generate / manage encryption keys" · "encrypt EBS volumes" · "encrypt data stored by CloudTrail" · "control access to keys"
TrapKeys are KMS or CloudHSM. Certificates are ACM. Passwords and API keys are Secrets Manager. Do not let "Certificate Manager" pull you in on a key question.

AWS CloudHSM

4× answer · 8× decoy

A dedicated single-tenant hardware security module in the cloud, for when compliance requires that keys live on hardware you alone control (FIPS 140-2 Level 3).

Signals"dedicated hardware" · "contractual or regulatory requirement" · "generate and use your own keys" · often paired with KMS on Choose TWO

Amazon Macie

4× answer · 9× decoy

Uses machine learning to discover, classify and protect sensitive data in Amazon S3 — personally identifiable information and credentials.

Signals"PII" · "sensitive data" · "intellectual property" · "classify data" · nearly always mentions S3

Amazon Inspector

4× answer · 42× decoy

Automated vulnerability assessment of EC2 instances and container images — software CVEs and unintended network exposure.

Signals"vulnerabilities" · "automated security assessment" · "unintended network accessibility of EC2 instances"
TrapForty-two appearances as a wrong option — the single most over-offered decoy in the corpus. It is only about vulnerabilities in EC2 workloads. Account-level security checks are Trusted Advisor; sensitive data is Macie; threat detection is GuardDuty.

Amazon GuardDuty

1× answer · 15× decoy

Continuous threat detection: analyses CloudTrail, VPC Flow Logs and DNS logs for malicious or unauthorised behaviour and raises findings.

TrapIt detects and alerts. It never blocks anything. Right answer once in 1,142 questions; wrong option fifteen times.

AWS Certificate Manager (ACM)

2× answer · 21× decoy

Provisions, manages and renews SSL/TLS certificates for AWS services, at no cost for public certificates.

Signals"SSL" · "TLS" · "HTTPS" · "certificate"
TrapTwenty-one decoy appearances, mostly in encryption key questions. Certificates ≠ keys.

Amazon Cognito

1× answer · 18× decoy

Sign-up, sign-in and access control for your application's end users — including social and enterprise identity federation.

TrapCognito is for your app's users. IAM is for people and services using your AWS account. Eighteen decoy appearances live entirely on that confusion.

AWS Directory Service

1× answer · 6× decoy

Managed Microsoft Active Directory in AWS, and connectors that let you keep using an existing on-premises directory.

Signals"Active Directory" · "existing on-premises identity management" · "single sign-on to AWS from a corporate directory"

AWS Secrets Manager

0× answer · 15× decoy

Stores and automatically rotates database credentials, API keys and other secrets.

TrapFifteen decoy appearances, zero correct — almost always offered in encryption key questions where KMS is the answer. Secrets Manager holds passwords, not keys.

AWS Security Hub

0× answer · 6× decoy

A single pane of glass aggregating findings from GuardDuty, Inspector, Macie and partner tools, and running automated best-practice checks.

AWS Firewall Manager · AWS Network Firewall

0× answer · 3× decoy

Firewall Manager centrally administers WAF and Shield rules across many accounts. Network Firewall is a managed network-layer firewall for a VPC.

AWS IAM Identity Center

not seen in corpus

Formerly AWS SSO. One sign-in across all your AWS accounts and business applications, connected to your existing identity provider.

Amazon Detective · AWS Audit Manager · AWS RAM

0× answer · 6× decoy

Detective investigates the root cause of a security finding. Audit Manager automates evidence collection for audits. Resource Access Manager shares resources between AWS accounts.

Management and Governance

18 services

AWS Organizations

26× answer · 33× decoy

Centrally manages many AWS accounts: consolidated billing into a single bill, volume discounts from combined usage, Reserved Instance and Savings Plans sharing, and Service Control Policies that cap what member accounts may do.

Signals"multiple AWS accounts" · "single/aggregated bill" · "volume discounts across accounts" · "centrally manage governance" · "restrict which services member accounts can use" (SCPs)
TrapRI sharing is on by default. To confine a Reserved Instance to one account you turn sharing off from the management account — options that say "enable sharing" are inverted.

AWS Trusted Advisor

19× answer · 53× decoy

Inspects your account and recommends improvements in five categories: cost optimization, performance, security, fault tolerance and service limits. Basic and Developer plans get a core subset; Business and Enterprise get all checks.

Signals"security groups with unrestricted access" · "service limits" · "idle or underutilised resources" · "best practice checks" · "MFA on the root account" · "S3 bucket permissions"
TrapFifty-three decoy appearances. It checks your account's configuration against best practices — it does not monitor metrics (CloudWatch), record changes (Config), or log API calls (CloudTrail).

Amazon CloudWatch

15× answer · 39× decoy

Metrics, logs and alarms. Collects performance data (CPU, network, disk), stores application logs, and triggers alarms and actions when a threshold is crossed — including billing alarms.

Signals"monitor CPU utilization" · "metrics" · "alarm" · "billing alarm" · "notify when a threshold is breached" · "application logs"
TrapCloudWatch answers how is it performing. CloudTrail answers who did it. Config answers what changed. A billing alarm is CloudWatch; a budget with a threshold is AWS Budgets.

AWS CloudTrail

14× answer · 43× decoy

Records every API call made in your account — who made it, from what IP, when, and what happened. The audit trail for governance and forensics.

Signals"who deleted / terminated / created it" · "API call history" · "unauthorized API calls" · "log of all access to resources" · "user activity in the Management Console"

AWS Config

14× answer · 44× decoy

Records the configuration of your resources over time, evaluates them against rules, and flags — or remediates — non-compliant resources.

Signals"configuration changes" · "how a resource changed over time" · "evaluate resources against a desired configuration" · "identify non-compliant resources" · "change management audit"
TrapCloudTrail and Config both say "audit". CloudTrail = the action and its actor. Config = the state of the resource and whether it complies.

AWS CloudFormation

13× answer · 14× decoy

Infrastructure as code. A template describes your resources; CloudFormation provisions them, repeatably, in any account or Region. Free — you pay only for what it creates.

Signals"infrastructure as code" · "template" · "programmatically define resources" · "replicate an environment in another Region" · "automate provisioning"

AWS Auto Scaling

17× answer · 12× decoy

Adds and removes capacity automatically as demand changes — the mechanism behind elasticity, and the reason you stop paying for idle resources.

Signals"traffic fluctuates" · "flash sale" · "unpredictable demand" · "avoid paying for underutilised capacity" · "no capacity planning decisions"
TrapOn highly available architecture Choose TWO questions, the pair is almost always Auto Scaling + Elastic Load Balancing.

AWS Health Dashboard

9× answer · 9× decoy

Two views. The Service Health view is the public status of every AWS service in every Region. The Personal Health view is personalised to your account: events affecting your resources, plus proactive notice of scheduled maintenance.

Signals"personalized" · "your resources" · "proactive notification" · "scheduled changes" → Personal. "status of all AWS services in all Regions" · status.aws.amazon.com → Service.

AWS Systems Manager

2× answer · 18× decoy

Operational control of your fleet: patch management, running commands across many instances at once, Session Manager shell access, and Parameter Store for configuration.

Signals"apply patches on a schedule" · "run a command across all instances" · "operate at scale" — including patching databases you run on EC2

AWS Control Tower

2× answer · 0× decoy

Sets up and governs a secure, well-architected multi-account environment — a landing zone with guardrails, built on Organizations.

Signals"multi-account environment" + "automate and govern" · "landing zone" · "guardrails"

AWS Management Console · AWS CLI · SDKs

10× answer combined

The three ways to interact with AWS: a web interface, a command line for scripting, and SDKs for code. Programmatic access needs an access key ID and a secret access key.

Signals"scripts to manage AWS resources" → CLI · "web-based user interface" → Console · Choose TWO on "valid ways to interact with AWS" usually wants Console + CLI

AWS Service Catalog

0× answer · 12× decoy

A catalogue of IT services your own organisation has approved for use on AWS.

TrapTwelve decoy appearances, zero correct. It is repeatedly offered where AWS Marketplace is the answer. Service Catalog = your org's internal approved products. Marketplace = third-party software you can buy.

AWS Well-Architected Tool

0× answer · 6× decoy

Reviews your workload against the six pillars — operational excellence, security, reliability, performance efficiency, cost optimization, sustainability — and reports the gaps.

AWS Resource Groups and Tag Editor

1× answer · 4× decoy

Groups resources by tag and edits tags in bulk. Cost allocation tags are how you break a bill down by department, project or environment.

Signals"separate / track costs by department, team, project or environment"

Not services, but they decide the questions

The in-scope list names services only. These are the concepts those services get wrapped in — and in your practice exams they accounted for more misses than any single service did.

Shared responsibility model
"of the cloud" — hardware, the global infrastructure, physical security, the hypervisor, managed-service patching, decommissioning disksAWS's responsibility
"in the cloud" — your data, encryption choices, IAM and permissions, security group and firewall configuration, guest OS patching on EC2, backups of your dataCustomer's responsibility
Patching the OS under RDS, Lambda, DynamoDB — a managed serviceAWS
Patching the OS on EC2, or a database you installed on EC2Customer

"unpredictable" · "short-term" · "cannot be interrupted" · no commitmentOn-Demand
"steady state" · "predictable" · "1 or 3 year commitment" · up to 72% offReserved Instances / Savings Plans
"flexible start and end times" · "can be interrupted" · up to 90% offSpot Instances
"licensing tied to physical cores" · "regulatory requirement for dedicated hardware"Dedicated Hosts

"disaster recovery" · "geographically isolated" · "data residency" · "global latency"Multiple Regions

Which services are global, not regionalIAM, Route 53, CloudFront, Organizations, WAF
